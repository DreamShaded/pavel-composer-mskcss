# Иллюстрации-улики

Каждая картинка — «фото улики» в деле. Пока файла нет, слайд показывает заглушку с описанием сцены.
Формат: `.webp`, 4:3.6 (например 1200×1080), сепия/нуар, единый стиль на всю колоду.

Общий стиль для промпта: *vintage noir detective case photo, sepia, film grain, hand-drawn ink illustration, dramatic side light, no text*.

| Файл | Сцена |
|------|-------|
| `01-pifpaf.webp` | Хор зверей на сцене оперного театра, мультипликационная пародия на оперу |
| `02-luther.webp` | Слева пьяницы у кабака поют песню; справа монах у храма зовёт внутрь той же мелодией; Мартин Лютер в центре |
| `03-bach-frederick.webp` | Бах пишет ноты; слева Фридрих Великий играет на флейте; справа рак кусает себя за хвост |
| `05-don-giovanni.webp` | Дон Жуан за ужином, музыканты играют, на стене афиша «Свадьбы Фигаро» |
| `06-tchaikovsky.webp` | Слева девушки водят хоровод у берёзы; справа Чайковский дирижирует оркестром |
| `08-dies-irae.webp` | Смерть с косой на кладбище, скелеты; надпись DIES IRAE (единственная картинка с текстом) |

| `11-star-wars.webp` | Композитор за дирижёрским пультом; за спиной Кощей Бессмертный и три апельсина |
